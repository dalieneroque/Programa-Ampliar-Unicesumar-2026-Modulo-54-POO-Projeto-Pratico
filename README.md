# 🏎️ Projeto: Jogo de Corrida

O projeto principal desenvolvido durante as monitorias foi um **jogo de corrida em Java**, utilizando Programação Orientada a Objetos e a biblioteca Swing.

A aplicação permite que diferentes tipos de veículos participem de uma corrida, cada um com seu próprio comportamento de aceleração.

O projeto foi utilizado como laboratório prático para demonstrar como classes, objetos, herança e polimorfismo trabalham juntos na construção de um sistema.

---

## 🏁 Como funciona o jogo?

O jogo apresenta diferentes veículos participando de uma corrida. O objetivo é acompanhar a movimentação dos participantes e identificar qual veículo alcança primeiro a linha de chegada.

### 🚗 Veículos participantes

- 🏎️ **Carro:** possui aceleração progressiva;
- 🏍️ **Moto:** possui aceleração variável;
- 🚛 **Caminhão:** possui aceleração mais moderada.

### ⚙️ Funcionamento da corrida

- Os veículos são posicionados na linha de largada;
- A corrida é iniciada ao pressionar a tecla `ENTER`;
- Cada veículo executa sua própria regra de aceleração;
- A posição e a velocidade dos veículos são atualizadas durante a corrida;
- A movimentação é apresentada graficamente na tela;
- Ao alcançar a linha de chegada, o vencedor é anunciado.

### 🖥️ Recursos implementados

- Interface gráfica utilizando Java Swing;
- Representação visual dos veículos;
- Movimentação dos veículos durante a corrida;
- Diferentes regras de aceleração;
- Controle da corrida por temporizador;
- Identificação da linha de chegada;
- Exibição do nome e da velocidade dos participantes;
- Identificação e anúncio do vencedor;
- Reinicialização dos veículos para uma nova corrida.

# 🧠 Aprendendo POO através do jogo

A proposta foi fazer com que cada conceito de POO fosse apresentado e relacionado a uma necessidade do projeto.

Por exemplo:

```text
Precisamos representar diferentes veículos
              ↓
       Criamos uma classe
              ↓
       Criamos objetos
              ↓
       Definimos atributos
              ↓
       Implementamos métodos
              ↓
       Utilizamos construtores
              ↓
       Aplicamos encapsulamento
              ↓
       Criamos diferentes tipos de veículos
              ↓
       Utilizamos herança
              ↓
       Aplicamos polimorfismo
              ↓
       Trabalhamos com classe abstrata
              ↓
       Implementamos comportamentos específicos
              ↓
       Construímos o jogo de corrida
```

Dessa forma, os alunos puderam compreender não apenas o que é POO, mas também por que determinados conceitos são importantes durante o desenvolvimento de um projeto.

# 💡 Metodologia

A metodologia utilizada foi baseada em **aprendizagem prática, desenvolvimento incremental e resolução de problemas**.

Durante as monitorias, os conteúdos foram trabalhados por meio de uma sequência que relacionava teoria e prática:

```text
🏁 Apresentação de um problema
             ↓
💭 Raciocínio lógico
             ↓
📚 Explicação do conceito de POO
             ↓
💻 Implementação no código
             ↓
🏎️ Aplicação no jogo
             ↓
🧪 Testes e observação dos resultados
             ↓
🎯 Exercícios e desafios
```

O desenvolvimento do jogo permitiu que os alunos acompanhassem a aplicação dos conceitos diretamente no código, compreendendo como diferentes partes de um sistema trabalham em conjunto.

Além da implementação, foram propostas perguntas, exercícios e desafios para estimular o raciocínio lógico, a participação e a autonomia na resolução de problemas.
